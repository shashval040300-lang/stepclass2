# Week 4 - Array Problems

Java solutions and sample outputs for all five Category C practice problems and all five Category C assignment problems.

## Files

- `ArrayWeek4Practice.java` - Two Sum, Best Time to Buy and Sell Stock, Contains Duplicate, Merge Two Sorted Arrays, and Rotate Array.
- `ArrayWeek4Practice-output.txt` - Output from the practice examples in the problem sheet.
- `ArrayWeek4Assignment.java` - Product of Array Except Self, Maximum Subarray, 3Sum, Subarray Sum Equals K, and Find Minimum in Rotated Sorted Array.
- `ArrayWeek4Assignment-output.txt` - Output from the assignment examples in the problem sheet.

## Run

From this directory, compile and run either program with:

```sh
javac ArrayWeek4Practice.java
java ArrayWeek4Practice

javac ArrayWeek4Assignment.java
java ArrayWeek4Assignment
```

The methods are static so they can also be called directly from another Java class.
