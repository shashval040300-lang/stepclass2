# Week 2 - Strings

Java solutions and sample output for all five Week 2 live-coding practice problems and all five Week 2 assignment problems.

## Files

- `Week2Practice.java` - Vowel/consonant counts, student CSV parsing, file extension validation, phone masking, and transaction-reference validation.
- `Week2Practice-output.txt` - Example output for the practice problems.
- `Week2Assignment.java` - PIN length validation, word reversal, inventory CSV parsing, ISBN normalization, and stop-word-filtered word frequencies.
- `Week2Assignment-output.txt` - Example output for the assignment problems.

## Run

```sh
javac Week2Practice.java
java Week2Practice

javac Week2Assignment.java
java Week2Assignment
```
