# Week 1 - Strings and Arrays

Java solutions and sample output for all five Week 1 live-coding practice problems and all five Week 1 assignment problems.

## Files

- `Week1Practice.java` - Rock-Paper-Scissors, palindrome checks, BMI report, first non-repeating character, and customer-name reversal.
- `Week1Practice-output.txt` - Example output for the practice problems.
- `Week1Assignment.java` - Duplicate seats, typing accuracy, longest traffic-signal streak, inventory balance, and word-length counts.
- `Week1Assignment-output.txt` - Example output for the assignment problems.

## Run

```sh
javac Week1Practice.java
java Week1Practice

javac Week1Assignment.java
java Week1Assignment
```

The Rock-Paper-Scissors demo uses a seeded random generator so its sample output is reproducible.
