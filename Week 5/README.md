# Week 5 - Arrays and Methods

Java solutions and sample output for all five Week 5 Category C practice problems and all five assignment problems.

## Files

- `Week5Practice.java` - In-place score bonus, duplicate team lookup, one-pass top-three scores, seating row classification, and overloaded placement eligibility with ranking.
- `Week5Practice-output.txt` - Sample output for the practice set.
- `Week5Assignment.java` - Captain multipliers, duplicate player lookup, one-pass min/max spread, match grid classification, and fantasy draft ranking.
- `Week5Assignment-output.txt` - Sample output for the assignment set.

## Run

```sh
javac Week5Practice.java
java Week5Practice

javac Week5Assignment.java
java Week5Assignment
```
